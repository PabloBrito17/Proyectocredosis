# FirstStep SV

Aplicación MVP de prototipo para una plataforma de primera oportunidad en El Salvador.

## Requisitos
- Node.js 18+
- npm

## Instalación
```bash
npm install
```

## Ejecutar localmente
```bash
npm run dev -- --host 0.0.0.0
```

## Build de producción
```bash
npm run build
```

## Funcionalidades demo
- Landing page con narrativa y CTA para jóvenes.
- Explorador de vacantes con búsqueda, filtros, ordenamiento y resultados vacíos.
- Vista de detalle con información clara y etiquetado demo.
- Perfil del candidato con guardado local y indicador de completitud.
- Flujo de postulación demo local con validación.
- Guardado de vacantes favoritas usando localStorage.
- Formulario de interés para empresas con confirmación local.
- Menú móvil y navegación accesible.

## Nota importante
Todos los contenidos son demostrativos: vacantes, formularios y datos se almacenan localmente en el navegador del usuario y no están conectados a un backend real ni a ninguna empresa real.
